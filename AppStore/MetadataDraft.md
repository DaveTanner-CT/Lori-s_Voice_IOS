## Description

Lori's Voice is a simple, customizable communication board designed to make everyday communication easier.

Tap a tile and Lori's Voice speaks the selected word or phrase aloud. Tiles can contain short labels, complete spoken sentences, emoji, colors, or personal photos. Related choices can be grouped into sub-tiles so frequently used communication stays easy to reach without crowding the screen.

Caregivers or family members can unlock Edit Mode to personalize the board, change tile order, add new choices, adjust the number of tiles shown on each page, select a voice, and choose a slower speaking rate when helpful.

Lori's Voice also includes a full-screen typing keyboard for messages that are not already available as tiles.

The app is designed to work offline. Communication-board information is stored locally on the device, and Lori's Voice does not require an account or sign-in. Users can create a backup file and restore it on another device using standard iOS sharing and file tools.

Key features include:

- Large customizable communication tiles
- Spoken words and full phrases
- Personal photos or emoji on tiles
- Sub-tiles for additional choices
- Built-in typing-to-speech keyboard
- Adjustable Apple voices and speaking speed
- Four-tile or six-tile page layouts
- PIN-protected editing
- Local device storage
- Backup and restore
- Offline operation
- No advertising

## App Review notes draft

Lori's Voice is an offline communication-board application. No account or login is required.

To review editing features, tap the unlocked padlock icon and enter the starter PIN `1234`. The PIN can be changed in Settings after entering Edit Mode.

All board content is stored locally on the device. The app does not require a backend service. The Save Board feature opens the standard iOS share sheet, and Load Board opens the standard iOS document picker.
